# NoS 戦歴ビューア

Nebula on the Ship（Among Us MOD）の試合を、サーバーに入らなくても見返せるビューアです。
マップの再生、会議の投票、役職や勝敗を、遊んだ全試合ぶん確認できます。

使うもの：Windows、Among Us（NoS）、Chrome か Edge

バージョン：**1.9**（ビューア左上の「ゲームデータ」の横にも表示されます）

## ダウンロード

1. **[ここをクリックして最新版のページを開く](https://github.com/MandanoRyuseigun/nos-record-viewer/releases/latest)**
2. 「Assets」の中の **`nos-record-viewer-v1.9.zip`**（バージョンの数字は最新のもの）を押してダウンロードします。
   - 「Source code (zip)」「Source code (tar.gz)」は GitHub が自動で付けるものなので、使わなくて大丈夫です。

## はじめに（1回だけ）

1. ダウンロードした zip を展開する前に、zip を右クリック →「プロパティ」→ 下のほうの「許可する」にチェック →「OK」。
   （これをしないと、Windows がスクリプトを止めることがあります）
2. 展開したフォルダを好きな場所に置きます（デスクトップやドキュメントなど）。
3. **Among Us（NoS）で1試合を最後（リザルト画面）まで遊んだあと、ゲームを閉じずに** `open-viewer.cmd` をダブルクリックします。
   - ここでゲームからマップ画像を保存します（最初の1回だけ）。
   - ゲームを起動しただけでは保存できません。NoS は試合が終わったあとに、マップ画像を取り出せるようにします。
   - 保存できていないと、マップがおおまかな形で表示され、ビューアのマップの上に案内が出ます。
   - 「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」を押します。

## ふだんの使い方

遊んだあとに `open-viewer.cmd` をダブルクリックします。新しい試合を取り込んでから、ビューアがブラウザで開きます。

- `viewer.html` を直接開いても、新しい試合は増えません。必ず `open-viewer.cmd` から開いてください。
- ビューアを開いたままのときも、もう一度 `open-viewer.cmd` を実行します（左上の ⟳ だけでは増えません）。
- 取り込んだ試合は `backup` フォルダに残ります。ゲーム側で古い試合が消えても、ビューアでは見られます。
- 新しいバージョンが出ると、ビューアの左上に「🆕 新しいバージョン … があります」と出ます。ダウンロードページから新しい zip を取ってきてください。
  - ビューアを開いたときに、GitHub に最新版の番号を問い合わせるだけです（半日に1回）。試合記録や名前などは送りません。インターネットにつながっていないときは何も出ません。

## 画面の見方

- **左の一覧**：試合は「**村**」（続けて遊んだ試合のまとまり）ごとに並びます。前の試合から1時間以上あくと、別の村になります。各試合には、何試合目か・時刻・勝敗・マップ・人数・試合時間が出ます。
  - 村の見出しの**名前**を押すと、その村の記録（村のページ）が開きます。名前以外の所を押すと、たたんだり開いたりできます。見出しの ✎ で、村に名前を付けられます（例：まんだ村）。
  - ✎ を押すと、前に付けた村の名前が下に並びます。押すとその名前になるので、日を空けて同じ村で遊んだときも入力しなくて済みます。
  - 試合の画面の上にある「✎ 名前」で、その試合にも名前を付けられます（例：シェリフ大活躍の回）。
  - 「マーク済み」で★の付いた試合だけに絞れます。上の欄に名前・役職・村や試合の名前・勝敗（「無効試合」「インポスター勝利」など）・マップ名を入れると絞り込めます。スペースで区切って入れると、全部を含む試合だけが出ます（例：「まんだ シェリフ」）。
  - **役職で絞り込み**：検索欄の下の「役職」と「誰が」で絞り込めます。役職（シェリフなど）か陣営（インポスター陣営・クルー陣営）を選び、「誰でも／自分／選んだ人」を選びます。例：「シェリフ」＋「自分」で、自分がシェリフだった試合だけになります。✕ でやめられます。統計・推移・キルの場所も、この絞り込みに合わせて変わります。
  - **勝敗のボタン**：「クルーメイト勝利」「インポスター勝利」「無効」を押すと、その試合だけになります（もう一度押すと解除）。「無効を隠す」にチェックすると、無効試合をいつも一覧と統計から外します。
  - 絞り込み中は、一覧の上に「🗑 絞り込んだ ○ 試合をまとめて消す」が出ます。たとえば「無効」ボタンを押してから使うと、無効試合をまとめて一覧から消せます。
  - **村を手で分ける・まとめる**：村の見出しの ⤓ で、ひとつ前（下）の村とまとめられます（休憩が長くて村が分かれたときなど）。試合の画面の「✂ ここから別の村」で、その試合から別の村にできます。どちらもすぐ出る「↶ 元に戻す」で戻せます。
  - ↑ ↓ キーで、一覧の前後の試合に移れます。
  - 統計画面の右上の「自分」か、試合の画面のプレイヤー表の上の「自分」で自分の名前を選ぶと、各試合に自分の役職と勝ち／負けが出ます。
  - 試合の画面でプレイヤーを選ぶと（プレイヤー表の行かマップ上のキャラをクリック）、一覧にはその人の役職と勝ち／負けが出ます。別の試合に移っても、同じ名前の人を選んだままになります。一覧の上の「✕ 解除」で戻せます。
- **🗑 消す**：試合の右上の 🗑 でその試合を、村の見出しの 🗑 でその村の試合をまとめて、一覧から消せます（練習で入っただけの試合など）。
  - 消した試合は、一覧にも統計にも入らなくなり、何試合目かの番号も詰まります。
  - **ビューアの中で見えなくするだけ**です。ゲームの記録や `backup` フォルダのファイルは消えません。
  - 消した直後に出る「↶ 元に戻す」か、一覧の上の「🗑 消した試合」から戻せます（試合を選んで右上の ↩、または村の ↩）。
  - 消した試合の一覧はブラウザに保存され、「設定を書き出す」にも含まれます。
- **★**：右上の★を押すと、マークを付けたり外したりできます。
  - このビューアの中だけの印です。ゲーム側のマークは変わりません。
  - 使っているブラウザに保存されます（Chrome と Edge では別々）。
  - ゲーム内でマークを外した試合は、次に `open-viewer.cmd` を実行したときに★が消えます。
- **試合結果**：上の帯に勝った陣営、勝因（例：「最後のインポスター陣営を会議で追放しました」「○○ が ○○ をキルして、インポスターの数がほかの生存者に並びました」）、勝った人を陣営ごとに表示します。
  - 帯の下の**ハイライト**に、最初のキル・いちばんキルした人・追放された人（陣営つき）・シェリフの成果（的中／誤射）・生き残りの人数が出ます。時刻のボタンを押すと、その場面に飛びます。
  - その下に日時・試合時間・マップ・ホスト・ターンと会議の数が出ます。
- **📷 画像にする**：試合の右上の 📷 を押すと、結果の帯・マップ・プレイヤーを1枚の画像にできます。「画像を保存」でダウンロードフォルダに保存、「コピー」で X や Discord にそのまま貼り付けられます。
  - マップは、そのとき表示している場面（再生位置）が写ります。見せたい場面まで再生してから押してください。
  - 「名前を隠す」にチェックすると、名前を P1・P2… に置き換えます（マップの上の名前も）。一緒に遊んだ人の名前を出したくないときに使ってください。村や試合に付けた名前も隠します（村は「〇月〇日 の村」になります）。
- **ターン / 会議**：ターンを選ぶとそのターンを再生できます。会議を選ぶと、通報・緊急会議の瞬間の位置と投票結果が出ます。
- **表示**：生存者・幽霊・オブジェクト（ベントと死体）・名前・軌跡の表示を切り替えます。
- **再生バーの印**：キルは▼（キルした人の色）、シェリフの誤射は◆（シェリフの色）。印を押すとその少し前に飛びます。
- **前のキル／次のキル**：ターンをまたいでキルからキルへ飛びます（Q / E キーでも可）。
- **続けて再生**：チェックすると、ターンの最後で会議の結果を少し表示して、次のターンを続けて再生します。
- **視界**：生きている人の視界を、その人の色の円で表示します（キャラを選ぶとその人だけ）。ゲームの設定は記録に残らないので、「視界の広さ…」で役職ごとに倍率を決めてください（最初はクルー側 ×0.5、赤い役職 ×1.5）。設定はブラウザに保存され、統計画面の「設定を書き出す」にも含まれます。
  - ※円の大きさは**目安**です。ゲーム画面のスクショから大きさを合わせていますが、実際の視界とまったく同じではありません。壁で見えなくなる部分や、停電などのサボタージュも反映されません。
- **軌跡**：ベントでの移動は点線で表示します。
- **操作**：▶ で再生（スペースキーでも可）、← → で3秒戻る・進む。マップはホイールで拡大、ドラッグで移動、⤢ で元に戻ります。再生バーの下の「？ 操作」で一覧を出せます。
- **広い画面**：画面の横幅が広いときは、出来事と投票結果をマップの右に並べます。
- **プレイヤー**：勝った人と負けた人に分けて、役職・タスクの進み具合・キル数・状態・会議ごとの投票先（数字は何回目の会議か）を表示します。クルー陣営の人がインポスター陣営に入れた票には ✓ が付きます。投票先は「投票先を表示」のチェックで隠せます。
  - 死んだ人の「ターン2 0:35」などを押すと、その場面に飛びます。
  - 行かマップ上のキャラをクリックすると、その人のターン全体の移動ルートが表示されます。
- **📊 統計**：左上の 📊 を押すと、取り込んだ全試合から勝率などを集計します。
  - プレイヤー表の右上の「☰ 表示する列」で、表に出す項目を選べます（「はじめの表示」「勝率だけ」「すべて表示」も選べます。選んだ列はブラウザに保存されます）。はじめは、よく見る列（試合・冠・勝率・陣営ごとの勝率・キル・最後まで生存・投票的中率）だけを出します。
  - **👑 何冠かを出す**：チェックすると、プレイヤー表に「冠」の列が出ます。持っている称号の数です（★の称号・殿堂の1位・役職の第一人者。★★★も1つ、同じ記録の殿堂の1位は全期間と村の名前ごとで1つと数えます）。数字にマウスを乗せると、どの称号かが出ます。
  - **🔍 名前で探す**：名前を入れると、その人がプレイヤー表のいちばん上に出ます（右上の「自分」の選択肢でも上に出ます）。ひらがなとカタカナは区別しません。
  - プレイヤーごとの試合数、勝率、クルー陣営勝率・インポスター陣営勝率・シェリフ勝率（その陣営・役職だったときの勝率）、キル数、キルされた数、最初にキルされた回数と割合（その試合で1人目の犠牲者になった試合）、最後まで生存した割合、被追放率（会議で追放された割合を、クルー陣営のとき＝疑われやすさ、インポスター陣営のとき＝バレやすさ、に分けて表示）、投票的中率（クルー陣営のときにインポスター陣営へ投票した割合）、シェリフ的中率（シェリフのときインポスター陣営を撃てた割合。誤射も含む）、通報した回数、緊急会議を開いた回数、ターン1（最初の会議の前）で緊急ボタンを押した回数、スキップ率（会議で投票したうちスキップした割合）
  - 役職ごと・マップごとの勝率。役職表の割合は「のべ人数」（その役職になった人数の合計。クルーメイトは1試合に約7人）で割った、1人あたりの値です。プレイヤーの行をクリックすると、その人の役職別の成績になります。
  - 右上で集計する**村**を選べます（すべての村／最近3つ・5つの村／ひとつの村）。その夜だけの成績や「いちばん勝った人」を見るときに使います。
  - 同じ名前を2回以上付けた村は、「同じ名前の村をまとめて」から選ぶと、その村で遊んだ全部の日をまとめて集計できます。
  - **相手ごとの成績**：プレイヤーの行を選ぶか「自分」を選ぶと、その人から見た相手ごとに、一緒の試合数・同じ陣営のときの勝率・インポスターの相棒のときの勝率・敵どうしのときの勝率・キルした／された回数・投票した／された回数が出ます。
  - **村ごとの推移**：村ごとの勝率を折れ線で表示します（人を選んでいなければクルーメイト勝率）。右上で「同じ名前の村」や「最近3つ・5つの村」を選ぶとその村だけを、それ以外はすべての村を古い順に並べます（ひとつの村を選んだときは、その村を大きい点で示します）。
  - **キルが起きた場所**：マップの上に、キルされた場所を赤い濃淡で重ねます。人を選んでいると「その人がキルされた場所」「その人がキルした場所」にも切り替えられます。右上で村を選ぶと（同じ名前の村をまとめて、も含む）、その村の試合のキルだけを表示します。
  - 左の「マーク済み」や検索欄、勝敗・役職の絞り込みがそのまま反映されます（例：名前を入れると、その人がいた試合だけで集計）。上の「対象」に、いま効いている絞り込みが出ます。
  - 同じ名前は同じ人として数えます。勝率は無効試合を除いて計算します。
  - **名前を変えた人をまとめる**：プレイヤー表の左のチェックで2行以上選び、「まとめた後の名前」を選んで「まとめる」を押します。元に戻すときは、表の上の「↶ 元に戻す」（まとめた直後）か、別名の横の「↶ 元に戻す」を押します。「まとめをすべて元に戻す」で全部解除できます。
  - **名前を変える**：プレイヤー表の名前の横の ✎ で、統計や一覧での表示名を変えられます（まとめなくても1人だけ変えられます。例：ゲーム内の名前がころころ変わる人を、あだ名でそろえる）。すでにいる別の人の名前にすると、その人とまとめます。戻し方はまとめたときと同じです。ゲームの記録は変わりません。
  - **設定の引き継ぎ**：まとめた名前・★マーク・視界の広さ・村や試合の名前・自分の名前・消した試合・村の分け方は、使っているブラウザの中に保存されます（Chrome と Edge、別の PC では別々）。統計画面の右上の「⤓ 設定を書き出す」でファイル（`nos-viewer-settings_日付.json`、ダウンロードフォルダに保存）にでき、別のブラウザや PC で「⤒ 設定を読み込む」を押してそのファイルを選ぶと引き継げます。ビューアにドロップしても読み込めます。読み込むと今の設定に追加されます。
    ブラウザのデータを消す前や PC を買い替える前に、書き出しておくと安心です。名前や★などを変えてから3日以上書き出していないと、ビューアの左上でお知らせします（✕ で3日後まで消せます）。
  - **設定の自動読み込み**：書き出したあとに `open-viewer.cmd` を実行すると、ダウンロードフォルダ（またはビューアのフォルダ）にあるいちばん新しい設定ファイルが `backup\settings` にコピーされます。別のブラウザや別の PC でビューアを開くと、その設定が自動で読み込まれます（読み込むのは新しいファイルのときだけで、今の設定に追加されます）。
    つまり、**設定を書き出してからフォルダごとバックアップ・コピーすれば、試合・マップ画像・設定がすべてそろいます**。うまく読み込まれないときは「⤒ 設定を読み込む」で手動で読み込んでください。このまとめはこのブラウザに保存され、ゲームの記録は変わりません。
  - ゲーム側は100試合までしか残りませんが、`open-viewer.cmd` で取り込んだ試合は `backup` に残るので、統計は遊んだぶんだけ増えていきます。
- **👤 プレイヤーページ**：左上の 👤、または統計のプレイヤー表の名前の横の 👤 で、1人の成績を1ページにまとめて見られます。右上で別の人や、集計する村（統計と同じ）を選べます。「🔍 名前で探す」に名前を入れて Enter でも、その人のページに移れます。右上の 📷 で、成績・受賞・自己ベストと累計・相性を1枚の画像にできます（横長・縦長、名前を隠す設定もあり）。
  - 見出し（受賞・称号など）を押すと、その欄をたためます（たたんだ欄はブラウザに覚えます）
  - 試合数・勝率・陣営ごとの勝率・キル・生存率
  - **受賞**：村ごとの表彰で、この人がもらった賞とその回数
  - **称号**：同じ賞を 3回で★、5回で★★、10回で★★★（例：★★名探偵）。殿堂の1位（全期間・村の名前ごと）には「歴代連勝王」「〇〇村の連勝王」、役職の第一人者には「シェリフの第一人者」のような称号が付きます。いちばん上の称号が名前の横に出ます（📷 の画像にも出ます）。称号はいつも全部の村で数えます。あと1回で★が付く賞は「もうすぐ★」に出ます。そのほかは「そのほかの次の★まで」を開くとわかります
  - **自己ベスト**：殿堂と同じ記録（1試合の最多キル・最速の死亡・最長連勝など）で、この人のいちばん。全期間の殿堂で3位以内なら 🥇🥈🥉 が付きます（右上で村を選んでいて値がちがうときは「全期間 🥈 ○○」と添えます）
  - **累計**：勝ち数・キル数・受賞数（殿堂で3位以内ならメダル付き）、クルー陣営のときのタスク完了率、ベントに入った回数、歩いた距離、幽霊だった時間、インポスター陣営になった回数
  - 役職ごとの成績、村ごとの勝率の推移
  - **相性**：いちばん勝てる相棒・頼れる味方・苦手な相手・よくキルする（される）相手・よく投票する（される）相手と、相手ごとの表
  - 会議（通報・緊急会議・スキップ率・投票的中率）とシェリフの成績、キルした／された場所、最近の試合（押すとその試合を開きます）
- **⚔️ 2人の比較**：プレイヤーページの右上の「⚔️ 比べる…」で相手を選ぶと、2人を並べて見られます（相手は一緒に出た試合の多い順に並びます）。
  - 2人が一緒に出た試合の数、味方になった回数と勝率、インポスター相棒、敵どうしのときにどちらが勝ち越しているか、キルし合った数、投票し合った数
  - 成績を左右に並べます（勝率・陣営ごとの勝率・インポスターのときの1試合のキル・キルの合計・生存・投票的中率など）。「全部の試合」はそれぞれが出た試合すべて、「一緒の試合」は2人とも出た試合だけで数え、良いほうを太字にします。いつも一緒に出ている2人は、列を1組にまとめます
  - 一緒に出た試合の一覧（2人の役職と勝ち負け、味方か敵か、2人の間のキル）。押すとその試合を開きます
  - ⇄ で左右を入れかえられます。📷 で画像にもできます（名前を隠すと P1・P2 になります）。集計する村と左の絞り込みは統計と同じです
- **🏛️ 殿堂**：左上の 🏛️ で開きます。右上で数える村（全期間・村の名前ごと・最近3／5つの村・ひとつの村）を選べます。「村の名前ごと」には、1回だけ使った名前も出ます（統計の「同じ名前の村をまとめて」は2回以上の名前だけです）。ビューアに取り込んだ試合の中での記録で、一覧から消した試合と無効試合は数えません。検索・★マーク・役職の絞り込みは効きません。
  - **歴代記録**：1試合の最多キル・1ターンの最多キル（3キル以上）・最速の死亡・1試合でいちばん歩いた距離・1試合でいちばんベントに入った回数・いちばん長い／短い試合・1回の会議の最多票・シェリフの連続的中・最長連勝・最長連敗・人外の最長連続・1晩の最多勝・1晩の最多キル・いちばん試合をした夜・全勝した夜の最多試合（3試合以上）・通算の勝ち数・通算のキル数・通算の試合数・通算の緊急会議（緊急ボタンで会議を開いた回数）・通算の受賞数（金賞・銀賞の内訳つき）を、1位〜3位まで出します。まだ記録の無いものは、いちばん下にまとめて薄く出します。その下に「賞ごとの最多受賞」（その賞をいちばん多くもらった人）の表もあります（同じ記録は同じ順位）。日付のボタンでその試合（場面）や村のページに飛べます
  - 連勝・連敗は、その人が出た試合だけを順に並べて数えます（休んだ試合では途切れません。無効試合は飛ばします）
  - 人外の最長連続は、インポスター陣営になった試合が続いた数です（第三陣営になったら途切れます）
  - シェリフの連続的中は、シェリフで撃った弾を順に並べて、インポスター陣営に続けて当てた数です（誤射で途切れます。撃たなかった試合では途切れません）
  - **役職ごとのランキング**：役職ごとのなった回数・勝率と「第一人者」（その役職を3回以上やった人の中で勝率1位）。行を押すと、その役職になった人の成績（勝率・生存・被追放率と、キル・シェリフの的中・タスク完了率など役職ならではの数字）が出ます
  - 通算の試合数は、記録が自分の出た試合だけなので自分がいちばん多くなります。このため称号（皆勤王）は付けません
  - **称号の一覧**：何冠か（持っている称号の数の多い順）、殿堂の称号・役職の第一人者・賞の★を、だれが持っているかを一覧にします。称号はいつも全部の村で数えます
  - **📷**：各記録の1位を1枚の画像にできます（横長・縦長、名前を隠す設定もあり。名前を隠すと村の名前も「〇〇村」になります）
- **村のページ（村の記録）**：一覧の村の名前を押すと、その夜の記録が開きます。右上の「◀ 前の村」「次の村 ▶」で移れます。
  - 試合数・遊んだ時間・クルーとインポスターの勝ち数・参加者の数・平均試合時間
  - **表彰**：その夜のナンバーワンを、**金賞**（勝ちにつながる頑張り）と**銀賞**（勝ち負けには関係ないナンバーワン）で表彰します。同じ数の人は全員がもらえます。当てはまる人がいない賞は「該当者なし」と薄く出ます（表彰カードの画像には出ません）。
    - 金賞：🏆 最多勝・🔪 キル王・⚡ キルペは正義（1ターンで2キル以上）・🎯 名探偵（投票の的中率）・🔫 名シェリフ・🐕 警察犬（通報）・🛡️ 生き残り王・🎭 身代わり王（マッドメイトで吊られた）・📋 タスク王（クルー陣営のときのタスク完了率）
    - 銀賞：🔔 初手ボ王（ターン1の緊急会議）・📣 招集王（緊急ボタンで会議を開いた回数）・😇 悲劇の人（最初にキルされた・2回以上）・🥲 不憫枠（クルーなのに吊られた・2回以上）・🕳️ ベントの住人・👟 移動距離No.1・⛓️ 道連れ王（巻き添え）・🤔 人気者（投票された票）・⏭️ 平和主義者（スキップ率）・🟥 赤い人（インポスター陣営になった回数）・💥 自爆王（シェリフの誤射）・⏱️ 死亡RTA（いちばん早くキルされた）・🚔 現行犯王（キルして5秒以内に通報され、その会議で吊られた）・👻 霊界王（幽霊だった時間）・🐢 粘り王（いちばん長い試合で最後まで生きていたインポスター）
    - タスクは試合の終わりの数しか記録に残らないため、幽霊になってから終えた分も含みます。アドミン・バイタル・カメラの使用は記録に残らないため、賞にはできません。
  - **ハイライト**：その夜に殿堂の1位を塗り替えた記録（🎉 記録を更新。全期間と村の名前の殿堂で同じ更新のときは1行にまとめます。通算の記録は毎晩のびるので出しません）と、新しく取った称号（🎖️）、いちばん長い／短い試合、その夜の最初のキル、いちばん長い連勝、シェリフの的中・誤射、現行犯などの場面。ボタンを押すとその場面に飛びます。記録の更新と称号が7件以上あるときは、6件だけ出して残りはたたみます。
  - **参加者とその夜の流れ**：1人ずつ、試合の順に陣営（青＝クルー、赤＝インポスター）と勝ち負け（○／●）を並べます。「全敗」「ずっと人外」「3連勝」などのひとことも自動で付きます。名前を押すとプレイヤーページへ。
  - **試合の履歴**：その夜の試合（時刻・マップ・結果・決着・時間）。押すとその試合を開きます。
  - **📷 表彰を画像にする**：右上の 📷 で、表彰を1枚の画像にできます。横長（X 向け）と縦長（スマホ向け）を選べて、見本を見ながら保存・コピーできます。「名前を隠す」で P1・P2… にもできます（村の名前も隠れます）。

## うまくいかないとき

- **最新の試合が出ない**：試合が終わるたびに `open-viewer.cmd` をもう一度ダブルクリックすると、最新の試合が入ります（新しい画面で開きます。cmd を実行したあとなら、開いている画面の ⟳ でも最新になります）。ビューアの左下にも同じ案内があります。黒い画面に「[ERROR]」と出た場合は、その画面を渡してくれた人に見せてください。
- **マップの形がおおまか**：Among Us（NoS）で1試合を最後まで遊び、ゲームを閉じずに、もう一度 `open-viewer.cmd` を実行してください。
  新しいバージョンのフォルダに入れ替えたときは、前のフォルダの `assets.js` を新しいフォルダにコピーしても直ります。
  NoS をどこに入れていても、起動中のゲームから自動で探します。それでも取れないときは、黒い画面に出る「Game folder(s) checked」「Nebula server not found」などの文字を、ビューアを渡してくれた人に見せてください。

## 人に渡すとき

いちばん簡単なのは、このページの URL（https://github.com/MandanoRyuseigun/nos-record-viewer ）を送ることです。

ファイルを直接渡すときは、次の4つだけにしてください。

- `viewer.html`
- `open-viewer.cmd`
- `build-records.ps1`
- `README.md`

次のものは**入れないでください**。

- `records.js` と `backup` フォルダ：あなたの試合記録（一緒に遊んだ人の名前など）と、書き出した設定が入っています。
- `assets.js`：ゲームのマップ画像です。受け取った人の PC で、その人のゲームから作られます。

## 技術メモ

### 試合記録の場所と形式

```
%USERPROFILE%\AppData\LocalLow\Innersloth\Among Us\NebulaOnTheShip\GameRecords\
    20261111T143816Z_b577bad2.json   ← 1ファイル = 1試合（開始日時UTC_ID）
    Marked\                          ← ゲーム内でマークした試合
```

ゲーム側では、マークしていない試合は最新100件より古いものから消されます。

| キー | 中身 |
| --- | --- |
| `version` | 形式のバージョン（15, 16） |
| `mapId` / `inMapId` | 0 Skeld / 1 MIRA / 2 Polus / 4 Airship / 5 Fungle（`inMapId` はマップの種類違い） |
| `startedAtUtc` / `endedAtUtc` | 開始・終了時刻（UTC） |
| `endInfo.stages[]` | 勝利条件（`endConditionId`）、勝者の playerId（`winners`）、勝因（`phases`） |
| `playerResults[]` | 名前、色、役職（`roleId`、`roleText` は TextMeshPro のタグ付き）、タスク数、最終状態、`killerId` |
| `events[]` | キル・通報・緊急会議・追放などと、その瞬間の全員の座標（`positions`） |
| `voteResults[]` | 会議ごとの投票。`votedForId` が 253 ならスキップ、254 なら未投票 |
| `mapObjects[]` | ベントなどの位置 |
| `movement` | gzip を base64 にした JSON。ターンごとに `startTime`、`interval`（0.25秒）、`tracks[]`（`points` = x,y の並び、`states` = 状態） |

`states` の値は推定で、bit 1 = 死亡（幽霊）、bit 4 = ベント内、bit 32 = タスクなどの操作中です。

### マップ画像

Nebula はゲームの起動中、`http://127.0.0.1:27100` などでサーバーを動かしています（ポートは `BepInEx\LogOutput.log` の `Started. http://127.0.0.1:…` から読みます）。
`open-viewer.cmd` は、そこから `/api/maps`、`/maps/<mapId>-<inMapId>.png`、`/api/map-objects`、`/map-objects.png` を取得して `assets.js` に保存します。

ゲーム座標から画像のピクセルへの変換は Nebula のビューアと同じです。

```
px = (x / scale + centerX - originX) * pixelsPerUnit
py = (originY - (y / scale + centerY)) * pixelsPerUnit
```

`assets.js` が無いマップは、全試合で生存中のプレイヤーが歩いた場所から床を描きます。
